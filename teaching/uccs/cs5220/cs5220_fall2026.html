Overview

CS 5220 covers fundamental computer networking concepts and principles, guiding students to apply networking theory and design principles, verify their understandings, and build a solid foundation for creating innovations in today's Internet. This course lays foundations of network architectures, protocol design principles, and TCP/IP programming skills necessary for advanced graduate study and technical training in industry. In addition to core networking topics, this course integrates network security perspectives throughout, examining vulnerabilities and attack surfaces at each layer of the protocol stack. Students will gain hands-on experience through security labs.

Course Structure

We will have
  1. Lectures with network security topics interspersed at each protocol layer.
  2. Four non-grade homework assignments but four pop-up quizzes.
  3. One paper presentation: Papers List.
  4. Four SEED security labs from SEED Labs:
    • SEED Lab 1: DNS Local Attack (Details).
    • SEED Lab 2: TCP Attacks (Details).
    • SEED Lab 3: BGP Exploration and Attack (Details).
    • SEED Lab 4: ARP Cache Poisoning (Details).

SEED Lab Environment Setup

SEED Labs require a virtual machine environment. Students are responsible for setting up the SEED VM on their own computers. Please follow the setup instructions at SEED Lab Setup. Basic Linux command-line proficiency is expected.
